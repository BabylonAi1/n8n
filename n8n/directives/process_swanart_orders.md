# Directive: نظام إدارة طلبات وكلاء SwanArt

> هذا الملف وثيقة حية — حدّثه عند اكتشاف قيود API أو أخطاء جديدة أو مسارات أفضل.

==================================================
## 🏢 السياق التجاري (Business Context)
==================================================

**SwanArt** شركة لوحات كانفاس عراقية تقدم خدمة الوكالة:
- الوكيل يفتح صفحة بيع أونلاين ويبيع بأسعاره الخاصة.
- SwanArt تنفذ الطلب، تطبع اللوحة، وتوصلها لزبون الوكيل مباشرة.
- التسوية مالية أسبوعية: **فرق الحساب = مبلغ البيع - مبلغ الفاتورة = ربح الوكيل**.

**المنتج الحالي:** كانفاس (Canvas) بقياسات مختلفة فقط.

**تعريف الوكيل:** شخص أو جهة لديها قناة/صفحة بيع خاصة، يرسل طلبات زبائنه عبر مجموعة تيليكرام. SwanArt تنفذ وتوصل باسمه.

## 📌 مسار العمل (Node Flow) — n8n v2.10.2
==================================================

1. **Telegram Trigger** — استلام رسائل مجموعة الوكلاء.
2. **Code Node (مُجمّع الألبومات)** — يجمع الصور بنفس `media_group_id`.
3. **Wait Node** — انتظار 3 ثوانٍ لضمان استلام جميع صور الألبوم.
4. **Code Node (فلترة + ترقيم)** — منع تكرار التنفيذ، توليد `order_id` من `data/order_counter.json`.
5. **Telegram Node (Send Media Group)** — إرسال الصور لمجموعة المصممين.
6. **AI Node (Gemini)** — استخراج بيانات الطلب من النص.
7. **Code Node (ترتيب + تأمين)** — تحويل مخرج AI إلى JSON آمن لتيليكرام.
8. **Google Sheets Node** — إضافة صف جديد في شيت الطلبات.
9. **Telegram Node (Send Message)** — إرسال ملخص الطلب مع أزرار تفاعلية.

**مسار ثانوي:** Telegram Trigger (Callback Query) لمعالجة ضغطات الأزرار.

## 🔢 نظام ترقيم الطلبات
==================================================

- الصيغة: `#1001`, `#1002`, ... (رقم تسلسلي بسيط)
- مخزّن في: `data/order_counter.json`
- يقرأ السكربت الرقم الأخير، يزيد +1، يحفظ، يُعيد الرقم الجديد.
- **لا تبدأ من 1** — ابدأ من حيث يريد المستخدم (افتراضياً 1000).

## 🤖 قواعد الذكاء الاصطناعي (AI Prompt Rules)
==================================================

الـ AI Prompt يُخرج JSON صارم بدون نصوص تمهيدية وبدون علامات \`\`\`json.

**الحقول المطلوبة:**
`اسم_الزبون، العنوان، رقم_الهاتف، عدد_اللوحات، القياس، نوع_الاطار، السعر، ملاحظات_التصميم، نوع_الطلب`

**قواعد التصنيف التلقائي لنوع_الطلب:**
- كلمة "استبدال" أو "تبديل" → `"استبدال 🔄"`
- عدا ذلك → `"طلب جديد 🆕"`

**معالجة الأسعار العراقية:**
- أرقام صغيرة (40, 65, 120) = آلاف → `"40,000"` ، `"65,000"`
- "40 الف" → `"40,000"`

**الحقول الفارغة:** اكتب `"غير مذكور"` — لا تترك فارغاً ولا تحذف.

## 🔘 الأزرار التفاعلية (Callback Queries)
==================================================

الرسالة الأصلية تنتهي بـ `⏳ الحالة: بانتظار استلام مصمم...` وتحتوي:
- `[👨‍🎨 استلام التصميم]` → callback_data: `take_design`
- `[📦 تم التجهيز]` → callback_data: `order_ready`

**عند ضغط "استلام التصميم":**
1. Answer Callback Query (إخفاء التحميل) — Resource: `Callback`, Operation: `Answer`
2. تعديل الرسالة: استبدال "بانتظار..." بـ `👨‍🎨 قيد التصميم بواسطة: {اسم ضاغط الزر}`
3. تحديث الأزرار: إبقاء زر "تم التجهيز" فقط

**عند ضغط "تم التجهيز":**
1. Answer Callback Query
2. تعديل الرسالة: `✅ تم التجهيز والتسليم للتوصيل بواسطة: {اسم ضاغط الزر}`
3. إزالة جميع الأزرار (قفل الطلب)

## 🚨 أخطاء تاريخية — يجب تجنبها دائماً
==================================================

**1. خطأ تيليكرام (Bad Request: can't parse entities)**
- السبب: `*` في القياسات (مثل 60*90) تُكسر الـ HTML parse.
- الحل: استبدل `*` بـ `x`، وأزل `_ < > \`` في Code Node.
- الحل 2: `Parse Mode = HTML` في **جميع** عقد إرسال/تعديل رسائل تيليكرام.

**2. خطأ الألبومات (mediaItems.media is not iterable)**
- السبب: n8n v2.10.2 لا يقرأ المصفوفات إذا لم تُمرَّر صح.
- الحل: فعّل Expression ⚙️ بجانب حقل Media وأعطه `={{ $json.mediaArray }}`.
- أو: استخدم Custom API وأرسل `sendMediaGroup` JSON Body مباشرة.

**3. خطأ AI (Missing required parameter: 'messages')**
- السبب: n8n الحديث لا يدعم حقل `prompt` العادي.
- الحل: Resource: `conversation`، مرر الرسائل عبر `messages.values` (System ثم User).

**4. خطأ الأزرار (answerCallbackQuery not supported)**
- الحل: Resource: `Callback`، Operation: `Answer`. لا تستخدم CustomAPI لهذه العملية.

**5. خطأ JavaScript (Unexpected token / undefined)**
- الحل: اقرأ مخرج AI بمرونة:
  ```js
  let content = aiResponse.text || aiResponse.output || aiResponse.message?.content || "";
  content = content.replace(/```json/gi, "").replace(/```/g, "").trim();
  // ثم try/catch حول JSON.parse
  ```
