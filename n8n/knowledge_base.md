---

## 🤝 نموذج الوكالة
- **الوكيل:** شخص/جهة لديها صفحة/قناة بيع أونلاين
- **آلية العمل:**
  1. موظفة المبيعات عند الوكيل تنزل صور اللوحات + تفاصيل الطلب في كروب تيليكرام
  2. SwanArt تستلم الطلب، تطبع، وتوصل **باسم الوكيل** لزبون الوكيل
  3. SwanArt تستلم المال من الزبون
  4. تسوية مالية **أسبوعية** مع الوكيل

- **المصطلحات المالية:**
  - `مبلغ الفاتورة` = سعر الطلب على الوكيل (تكلفة SwanArt للوكيل)
  - `مبلغ البيع` = السعر الذي يبيع به الوكيل لزبونه
  - `فرق الحساب` = مبلغ البيع - مبلغ الفاتورة = **ربح الوكيل**
  - `مبلغ الفاتورة عند الوكيل` = ما دفعه الوكيل مسبقاً (للتسوية)

## 🤖 نظام الأتمتة

### الهدف
استلام رسائل موظفة المبيعات (صور + نص عشوائي)، تنظيمها بالذكاء الاصطناعي، وإرسالها كـ **أوردر ذكي منسق** لكروب مخصص.

### المرحلة الحالية
- التجارب في المجموعة الموجودة: `-5006780541`
- لاحقاً: كروب جديد مخصص للطلبات الذكية (Chat ID سيُضاف بعد الإنشاء)

### مسار الرسالة
```
كروب الوكيل (موظفة تنزل صور+نص)
        ↓
Telegram Bot Trigger (n8n)
        ↓
جمع ألبوم الصور + انتظار 3 ثوانٍ
        ↓
Gemini AI → استخراج JSON
        ↓
تنسيق + ترقيم الطلب
        ↓
إرسال أوردر ذكي (نفس الكروب حالياً → كروب جديد لاحقاً)
        ↓
Google Sheets ← حفظ البيانات
```

### حالات الطلب (في تيليكرام فقط، ليس في الشيت)

- 👨‍🎨 قيد التصميم بواسطة: {اسم}
- ✅ تم التجهيز والتسليم للتوصيل بواسطة: {اسم}
- 🚚 تم التوصيل

### نقص البيانات
إذا كان أي حقل مهم ناقص → النظام يكمل لكن يرسل **Reply** لموظفة المبيعات لتنبيهها

## 🚨 أخطاء تاريخية موثقة
1. `*` في القياسات تكسر Telegram HTML → استبدلها بـ `x`
2. ألبوم الصور في n8n v2.10.2 → مرّر المصفوفة عبر Expression مباشرة
3. AI Node في n8n الحديث → استخدم `messages.values` مع System+User roles
4. `answerCallbackQuery` → استخدم Resource: Callback, Operation: Answer
5. JSON من AI قد يحتوي ` ```json ` → نظّفه قبل JSON.parse
